## 🧱 Stack

Construído **sem frameworks e sem build step** — de propósito. Mostra domínio dos fundamentos antes de esconder tudo atrás de uma ferramenta:

| Camada | Tecnologia |
|---|---|
| Estrutura | HTML5 semântico |
| Estilo | CSS3 puro (custom properties, grid, clamp, animações) |
| Interatividade | JavaScript vanilla (IntersectionObserver, template literals, DOM API) |
| Deploy | Vercel (deploy contínuo) |
| Fontes | Google Fonts (Fraunces, IBM Plex Mono, Inter) |

## ✨ Funcionalidades

- **Terminal animado no hero** — digitação simulada da trajetória profissional, com fallback automático para quem usa `prefers-reduced-motion`
- **Timeline "commit-style"** — a carreira contada como um `git log`, do diário de classe ao primeiro código
- **Grid de projetos dinâmico** — os cards são renderizados via JS a partir de um array de dados, fácil de manter e escalar
- **Totalmente responsivo** — menu hambúrguer, grids que colapsam, tipografia fluida com `clamp()`
- **Reveal-on-scroll robusto** — animações de entrada com rede de segurança própria: nada trava invisível mesmo se o navegador abrir direto numa âncora

## 🛠️ Rodando localmente

Sem dependências, sem build. Clone e abra:

```bash
git clone https://github.com/dev-Lucena/Portif-lio---Victor-Lucena.git
cd Portif-lio---Victor-Lucena
```

Depois é só abrir o `index.html` no navegador, ou servir com qualquer servidor estático:

```bash
npx serve .
```
